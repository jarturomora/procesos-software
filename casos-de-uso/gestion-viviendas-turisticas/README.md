# Sistema de Gestión de Viviendas Turísticas

## Caso Práctico

Una empresa desea desarrollar una plataforma web para la gestión de viviendas turísticas. Los propietarios podrán registrar sus alojamientos, añadir fotografías, establecer precios por temporada y definir la disponibilidad de cada vivienda. Los clientes podrán buscar alojamientos utilizando filtros como ubicación, capacidad, precio o servicios disponibles, realizar reservas y efectuar pagos en línea.

El sistema deberá evitar reservas duplicadas para las mismas fechas y enviar confirmaciones automáticas tanto al propietario como al cliente. Además, los huéspedes podrán valorar su estancia y dejar comentarios una vez finalizada la reserva. Los administradores de la plataforma tendrán acceso a herramientas para supervisar la actividad, gestionar incidencias y bloquear anuncios que incumplan las normas de uso. La empresa también desea disponer de informes periódicos sobre ocupación, ingresos y valoraciones de los alojamientos. El objetivo es ofrecer una experiencia sencilla y segura tanto para propietarios como para viajeros.
