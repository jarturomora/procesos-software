# Casos Prácticos de Casos de Uso y Definición de Requisitos

En este apartado del repositorio encontrarás casos prácticos similares a los del examen. En todos los casos deberás hacer lo siguiente:

1. Identificar requisitos funcionales y no funcionales (al menos 10 entre ambos tipos)
2. Elaborar un diagrama de casos de uso
3. Crear el formato expandido de cada caso de uso

Los casos se presentan organizados por el curso académico donde se han trabajado en clase empleando la siguiente simbología:

* ✅ -> Caso práctico resuelto
* 🤔 -> Caso práctico pendiente de resolver

Las soluciones presentadas son ejemplos realizados por el autor del repositorio para ilustrar una posible respuesta.
